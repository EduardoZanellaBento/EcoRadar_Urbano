# Prints manuais (celular real)

Esta pasta fica **vazia de propósito**: aqui você (aluno) salva os prints tirados no seu próprio celular,
seguindo o checklist do `COMO_TESTAR.md`. Use exatamente estes nomes — a galeria `registros/index.html`
mostra automaticamente o que estiver nesta pasta quando for regenerada (`scripts/coletar-evidencias`
ou `node tests/scripts/gerar-relatorios.mjs`).

| Arquivo | O que registrar |
|---|---|
| `M01_expo_go_abrindo.png` | Expo Go abrindo o EcoRadar (após ler o QR code) |
| `M02_onboarding_celular.png` | Primeiro slide do onboarding |
| `M03_login_celular.png` | Tela de login com o teclado do celular |
| `M04_mapa_celular.png` | Mapa com ocorrências, estações e mananciais (Google Maps / Apple Maps) |
| `M05_registro_camera_gps.png` | Registro com foto tirada pela câmera e localização pelo GPS real |
| `M06_detalhe_foto_real.png` | Detalhe da ocorrência mostrando a sua foto |
| `M07_notificacao_alerta.png` | Notificação local do alerta (o admin dispara o cenário pelo navegador do PC) |
| `M08_banner_alerta_celular.png` | Banner do alerta dentro do app + badge na aba Alertas |
| `M09_modo_aviao_pendente.png` | Modo avião ligado: faixa "Você está offline" e envio pendente |
| `M10_sincronizado.png` | Modo avião desligado: envio sincronizado automaticamente |
| `M11_tempo_real_pc_celular.png` | Ocorrência registrada no navegador do PC aparecendo no celular sem recarregar |
| `M12_qualidade_ambiental_celular.png` | Tela de qualidade ambiental (IQAr, gráfico) |
| `M13_relatorio_compartilhado.png` | Folha de compartilhamento do PDF exportado |
| `M14_status_sistema_celular.png` | Status do sistema com todos os serviços online |
| `M15_tema_escuro_celular.png` | Qualquer tela no tema escuro |
